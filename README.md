# AzlinkPRO

**Amazon comparison tables, product images and a free AmaLinks Pro importer for WordPress.**

AzlinkPRO is a WordPress plugin for Amazon affiliate sites. Add products by ASIN and it builds a clean comparison table: the product photo, a short "Brand | Model" name, labeled feature highlights and a Check Price button with your own Associates tracking ID.

- Website: [azlinkpro.com](https://azlinkpro.com/)
- Documentation: [azlinkpro.com/documentation](https://azlinkpro.com/documentation/)
- Live demos: [azlinkpro.com/live-demos](https://azlinkpro.com/live-demos/)
- Video tutorials: [youtube.com/@azlinkpro](https://www.youtube.com/@azlinkpro)

## Free features (this repository)

- **Comparison tables in three layouts:** Full, Compact and Minimal
- **Amazon product lookup:** search Amazon or add an ASIN, and the title, photo and highlights fill in
- **Product image block:** a clickable Amazon product image for any post
- **AmaLinks Pro importer:** converts AmaLinks Pro comparison tables into AzlinkPRO tables and updates the shortcodes in your posts, with a backup and one-click rollback

AmaLinks Pro shut down in December 2025. Read [AmaLinks Pro Shut Down: What Amazon Affiliates Should Do Next](https://azlinkpro.com/amalinks-pro-shut-down/) for a 10-minute site check and how to move your tables.

## Install

Download the plugin from [azlinkpro.com](https://azlinkpro.com/pricing/) and upload it in **Plugins → Add Plugin → Upload Plugin**.

This repository holds the plugin's own source code. It leaves out the third-party [Freemius SDK](https://github.com/Freemius/wordpress-sdk) (the `vendor/freemius` folder) that handles licensing, so install from the download above rather than from this repository.
